# NAP (Negócio Aprimorado): demonstração

Este repositório contém **só os arquivos prontos** (o "build") da **demonstração web** do NAP, um aplicativo para MEIs e pequenos prestadores de serviço organizarem clientes, orçamentos, recebimentos, despesas e caixa.

- **Só dados fictícios.** A empresa "Estúdio Exemplo (demonstração)" e todos os clientes, valores e contatos são inventados. **Não digite dados reais.**
- **Nada é enviado a lugar nenhum.** Tudo fica no seu navegador (banco local), sem conta, sem login e sem telemetria. Dá para zerar com o botão "Reiniciar demonstração".
- **A primeira abertura leva cerca de 20 segundos** (o banco é criado no seu navegador); as seguintes, poucos segundos.
- O aplicativo de verdade é para **computador (Windows)**, com os dados numa pasta do seu computador e funcionamento sem internet. Ele **ainda não está disponível publicamente**; para pedir o instalador, use o e-mail de contato da própria demonstração.

O código-fonte fica em outro repositório (privado). Aqui não há código para editar: cada publicação substitui estes arquivos.
